# Handoff: Лендинг «Выездная кастом-зона» (Pinhead Studio)

## Overview

Новая страница услуги на сайте pnhd.ru. Цель — квалифицированные заявки от компаний,
event-агентств и организаторов мероприятий. Целевое действие — отправка формы
«Рассчитать стоимость».

Шапка и футер повторяют существующий сайт Pinhead Studio (Next.js): те же пункты
меню, телефон, кнопка «Сделать заказ», реквизиты. Их нужно переиспользовать из
кодовой базы, а не верстать заново — в макете они воспроизведены только для
контекста.

## About the Design Files

Файлы в `design/` — **дизайн-референсы, сделанные в HTML**. Это прототипы,
показывающие композицию, типографику, цвета и поведение. Это **не production-код**
и его не нужно копировать в проект как есть.

Задача — воссоздать эти макеты в существующем окружении сайта (Next.js + React),
по принятым в кодовой базе паттернам: компоненты, роутинг, стили, формы,
аналитика. Разметка из прототипа — источник значений (размеры, цвета, копирайт),
а не исходник.

Прототип написан в собственном рантайме предпросмотра (`support.js`, теги `<x-dc>`,
`<helmet>`, `<x-import>`) — открывается в браузере напрямую двойным кликом,
но в продакшен не переносится.

## Fidelity

**High-fidelity.** Цвета, типографика, отступы и копирайт финальные. Верстать
пиксельно по макету, используя шрифты и токены бренда из гайдбука Pinhead.

Что НЕ финально: фотографии (нужны финальные съёмки и видео первого экрана),
кейсы (сейчас 4 плитки: VK Fest, Пикник Афиши, FLOW FEST, Корпоратив),
названия площадок и цифры по кейсам.

## Interactions & Behavior

- **Якорные переходы.** Кнопки «Рассчитать стоимость» → `#form`, «Посмотреть
  форматы» → `#formats`. Меню шапки и футера ведут на `#formats`, `#stages`,
  `#cases`, `#faq`. Плавная прокрутка (`scroll-behavior: smooth`),
  `scroll-margin-top` под фиксированную шапку, если она залипающая.
- **Hover.** Единственный приём бренда — инверсия: заливка и текст меняются
  местами. Ничего не масштабируется, не поднимается, не меняет прозрачность.
  Ссылки меняют цвет на `#1D19EA` (на тёмном фоне — на `#B4FB53`).
- **Focus.** Контур `1px solid #1D19EA`.
- **Чипы формата.** Одиночный выбор, активный — синяя заливка. Выбор пишется в
  скрытое поле формы и отправляется в Bitrix24.
- **FAQ.** Нативный `<details>`; «+» → «−». Раскрытие мгновенное, без анимации
  высоты (или ≤200ms, `cubic-bezier(0.2,0,0,1)`).
- **Валидация.** Обязательные: имя, телефон, согласие. Телефон — маска
  `+7 (___) ___-__-__`, 11 цифр. Email — формат, если заполнен; Telegram —
  `@nickname`. Файл — PDF/DOC/DOCX/PPT/PPTX/ZIP до 20 МБ, один файл. Ошибки
  показываются после первой попытки отправки, затем — по `blur`.
- **Отправка.** Кнопка → состояние «Отправляем…», поля заблокированы. Успех —
  панель `#B4FB53` вместо формы. Ошибка сети — сообщение «Не удалось отправить,
  попробуйте ещё раз или напишите в Telegram» + повтор.
- **Анимация.** Бренд статичный: жёсткие смены состояний, без bounce/spring.
  `--duration: 200ms`, `--ease: cubic-bezier(0.2,0,0,1)`. Видео первого экрана
  (когда появится) — автоплей, muted, loop, `playsinline`, с постером-фото.

## State Management

- `formValues` — 13 полей (имя, компания, телефон, email/Telegram, город, дата,
  тип мероприятия, количество гостей, продолжительность, формат, бюджет, описание,
  файл).
- `selectedFormat` — один из `DTF | Шелкография | Мастер-класс | Мерч-зона`.
- `errors` — карта «поле → сообщение».
- `status` — `idle | submitting | success | error`.
- `consent` — boolean, блокирует отправку.
- Скрытые поля, собираются на монтировании: UTM-метки (`utm_source`, `utm_medium`,
  `utm_campaign`, `utm_content`, `utm_term`) из query и/или cookie, Client ID
  Яндекс.Метрики (`ym(ID,'getClientID',cb)`), номер визита Roistat
  (`roistat_visit`), referrer, `page_url`.
- Фиксированное значение проекта/услуги: **«Выездная кастом-зона»** — передаётся
  в Bitrix24 отдельным полем.
- Данные формы не должны теряться при ошибке сети (черновик в `sessionStorage`).

## Functional Requirements

- Адаптивная вёрстка.
- Интеграция формы с Bitrix24 (создание лида, поле услуги = «Выездная кастом-зона»).
- Передача UTM, Client ID Метрики, визита Roistat.
- Сообщение об успешной отправке.
- Защита от спама: honeypot + временна́я отсечка + капча на усмотрение бэкенда.
- Согласие на обработку персональных данных со ссылкой на политику.
- Редактируемость из админки: стоимость (три варианта), тексты секций, кейсы, FAQ.
- Ссылка на каталог (`/shop`).
- SEO: title, description, OG-теги, H1 один на странице, `<section>`/заголовочная
  иерархия, микроразметка Service/Offer, alt у всех фото.
- Производительность: WebP/AVIF, `loading="lazy"` для всего ниже первого экрана,
  `fetchpriority="high"` для фото первого экрана, preload шрифтов,
  явные `width`/`height`, видео — не более ~3 МБ с постером.

design/
  Выездная кастом-зона.dc.html     ← основной макет: 1A десктоп, 1B мобильный, 1C состояния формы

комментарии докладчика.
